# 实验结果与保留依据

终点轮廓误差按该时刻的等效半径归一化。分叉匹配按持续径向指尖的出现时间和方位统计。表中每行使用各自的配对对照。

| 对照 | 结果与分析 |
|---|---|
| 数值推进与全轨迹残差优化 | 短时椭圆的残差可以明显下降。较长时域出现局部回退，残差降低也可能伴随终点偏差上升。训练改用时间推进生成的闭合界面。 |
| 数据扩展与时间加密 | 64→96 初形改善了直接和四帧模型。96→128 的等曝光对照给几何模型带来约 0.83 个百分点的终点改善。更密的短步标签主要改善局部推进。 |
| 核心架构 | 128 初形同预算下，直接、四帧、几何模型的 $T=100$ 终点偏差依次为 26.36%、24.34%、21.77%。近期法向运动和几何分支值得保留。 |
| Self Forcing 与回放课程 | 四帧预测、长滚动回放和提高初形起步比例在若干对照中改善了自由滚动。提高初形起步比例后，两种子终点由 22.19% 降至 21.52%，曾自交案例由 4/16 降至 1/16。 |
| 预测修补与潜特征 | 多尺度频带修补、近邻修补、JEPA 未来特征和流式细化的收益随任务和种子变化，统一训练入口沿用直接监督与自由反馈。 |
| 物理输入、速度头与显式速度积分 | 多近邻和精确历史特征主要改善局部速度指标。直接替换历史尺度使终点变差。单独增加速度头和显式速度步进的整体收益有限，保留坐标推进。 |
| 双向轮廓与丰富损失 | `nn_direct` 的指尖与凹槽监督把终点偏差从 30.53% 降至 28.76%，两个种子方向一致。坐标模型在走偏后与同状态数值续算的扇区误差从 0.735% 降至 0.557%，终点偏差从 21.86% 升至 22.48%。保留可选指尖项，其他轮廓、法向、软占据、自交及组合项没有稳定的综合收益。 |
| 走偏状态的多步监督 | 在同一批 32 个训练起点上，短窗 $+0.5$ 和长窗 $+4$ 的独立测试扇区误差分别为 0.5430% 和 0.5433%，指尖对照为 0.5458%。两种子各训练 1,200 步，按热启动梯度范数校准辅助项。长窗相对短窗的局部收益方向在两种子间相反。 |
| 原轨迹纠偏 | 数值推进在 32 条独立测试路径中有 10 条在分叉扇区自然收缩，来自两个独立初形。短窗、长窗和指尖对照均为 0/32。延长同状态续算监督在此对照中没有解决原轨迹偏差。 |
