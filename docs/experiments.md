# 架构与训练实验记录

每项先记结果，再记分析。相对轮廓误差按对应时刻的等效半径 $R$ 归一化；分叉匹配以持续径向指尖的出现时间和方位为代理。跨条目的数字可能使用不同初形、时域、时间网格和预算，比较以各条标出的配对条件为准。

早期实验按章节给出 Git 提交与历史文件路径，可用 `git show <提交>:<路径>` 核对。

## 物理目标、初始化和早期网络

来源为 `f2a61ad` 的 `results/ellipse_short`、`results/ellipse_long`、`results/nn`，以及 `f1996f8` 的 `results/initialization_benchmark`。

- **短时椭圆的全时段界面优化**。**结果** 无额外扰动的 3:1 椭圆在 $T=20$ 的物理目标从 $9.56\times10^{-4}$ 降到 $8.25\times10^{-6}$。 **分析** 数值热启动后联合优化空间 Fourier 与时间样条系数可以降低短时残差。终点形态需要独立验算。
- **长时椭圆的闭合界面优化**。**结果** $T=1000$ 的目标从 $2.08\times10^{-4}$ 降到 $5.95\times10^{-5}$，最低法向速度为 $-0.00475$，轨迹出现局部回退。 **分析** 首次到达时间只能记录首次占据。长时预测改用完整闭合界面描述状态。
- **粗推进直接出解**。**结果** $T=5$ 用时约 0.025 秒，终点相对细推进差 0.0164%。$T=20$ 的终点差为 1.07%。 **分析** 粗推进本身已包含随形状变化的动力学信息，给热启动优化设定了有实际意义的精度和成本基线。
- **粗推进热启动后做全时段优化**。**结果** $T=5$ 用时约 8.70 秒，终点差为 0.0170%。$T=20$ 的终点差升至 2.9910%，独立速度残差 RMS 为 0.07853→0.00660。 **分析** 离散残差和终点误差排序发生反转，因此后续监督标签使用时间推进。
- **膨胀形状作轨迹初猜**。**结果** $T=5$ 和 $T=20$ 的终点差分别为 2.9165% 和 20.8716%，均高于粗推进。 **分析** 简单膨胀给出整体尺度，对沿界面的形变与指进缺少合适的起步信息。
- **逐段扩大优化时域**。**结果** $T=5$ 和 $T=20$ 的终点差为 5.0145% 和 21.9647%，均高于粗推进。 **分析** 增加时域课程没有把当前优化目标转成可测的终点收益。
- **无轨迹标签的短时 PINO**。**结果** $T=1$、$32^2$ 网格、8,000 个初形，留出物理损失从 0.01453 降到 0.00176。 **分析** 验证覆盖短时单调星形界面。复杂长时分叉与回退仍需另外检验。
- **单案例连续时间界面网络**。**结果** $T=1000$ 纯椭圆从数值轨迹热启动，2,048 点审计的独立物理残差 RMS 约 0.00389，846 个审计时刻均未检出自交。 **分析** Fourier 系数网络可以表达该条复杂长时轨迹。这个试验的初形固定，结果衡量的是单案例表达能力。
- **单案例网络的分阶段物理精修**。**结果** 先做 500 步再追加 300 步，早期使用 512 点、训练使用 1024 点与中点时间积分。物理目标 $2.497\times10^{-4}\to1.300\times10^{-5}$。 **分析** 提高分辨率和续训降低了单例的物理目标。2048 点独立审计仍需与训练目标分别报告。

## T=5、20、1000 的直接预测与第一版短窗更新

两种模型均在各自训练时域内评估，使用相同数据划分和 4,000 步预算。来源为 `c4cf2f9` 的 `results/supervised/comparison/summary.json`。

- **早期 T=1000 CurveFNO 先导**。**结果** 验证最优检查点为第 500 步，验证坐标 MSE 0.03082，终点 40.34%，8/8 条曾自交。 **分析** 单次长时直接查询可以覆盖完整时域，形状稳定性仍不足。来源为 `f1996f8:results/supervised/model/metrics.json`。
- **条件 Fourier 直接查询**。**结果** 在 $T=5$、20、1,000 的终点误差依次为 10.94%、18.89%、40.28%。 **分析** 从初形与时间直接查询，短时避开重复反馈的误差积累。长时界面偏差仍明显。
- **第一版短窗模型 nn_ins**。**结果** 同三档终点误差分别为 130.91%、196.01%、82.80%，每档逐例胜出数均为零。 **分析** 重采样与高频阻尼未能抑制短步误差在自由滚动中的累积。这组数据用于训练域内比较。

## T=20 同帧修补与潜特征

各组从同一直接预测出发，终点基线为 18.89%。两个数字分别对应两个种子。来源为 `c4cf2f9` 的 `results/supervised/world_t20` 与 `seed2`。

- **逐点同帧修补**。**结果** 终点约为 18.97% 和 18.97%。 **分析** 逐点输入对相邻弧段和空间近邻的表达有限。
- **沿弧长局部卷积修补**。**结果** 终点为 18.30% 和 17.97%。 **分析** 相邻弧段的局部形状信息带来小幅收益。
- **空间近邻修补**。**结果** 终点为 18.06% 和 17.91%。 **分析** 沿界面相隔而空间接近的弧段提供了窄缝两侧的几何信息。
- **单轮频带修补**。**结果** 终点为 18.14% 和 18.19%。 **分析** 低频轮廓和高频形变分开处理能改善这组短时预测。
- **重复两轮频带修补**。**结果** 终点为 17.44% 和 17.84%。 **分析** 第二轮延续了单轮收益，在这批初形上是最好的修补配置之一。
- **重复三轮频带修补**。**结果** 终点为 17.59% 和 18.25%。 **分析** 相对两轮均退步，重复应用修补器的收益存在上限。
- **JEPA 未来几何特征**。**结果** 终点为 18.08% 和 18.18%。 **分析** 潜空间预测能参与几何修补，当前设置的效果与近邻或频带修补相近。
- **修补器端到端展开**。**结果** 终点为 18.24% 和 18.12%。 **分析** 训练时展开修补过程，终点仍弱于相同种子的两轮频带修补。
- **同帧修补器加噪**。**结果** 终点为 21.05% 和 20.15%，均高于直接基线。 **分析** 合成噪声与实际粗预测的偏差结构存在差异。
- **交叉拟合预测训练修补器**。**结果** 终点为 18.29% 和 18.57%。 **分析** 用样本外预测提供更接近部署的偏差，收益小于重复频带修补。

## T=20 报警、截断与混合推理

来源为 `c4cf2f9:results/supervised/world_t20` 两个种子的 `verification.json`，实现见同一提交的 `src/nn_world/verify.py`。保留时长用物理时间单位，及时报警数的分母为各自 5 和 6 个违规案例。

- **不加门控的预测**。**结果** 两个种子的平均保留时长均为 20，及时报警为 0/5 和 0/6。 **分析** 完整保留预测提供了门控对照，也保留了全部超限轨迹。
- **仅几何门控**。**结果** 平均保留 16.70 和 15.16，及时报警为 0/5 和 1/6。 **分析** 这组几何检查较少截断，但大部分超限形态无法提前识别。
- **几何间隙门控**。**结果** 平均保留 1.06 和 0.79，及时报警为 5/5 和 6/6。 **分析** 间隙信号检出率高，代价是大幅缩短可用区间。
- **预测分歧门控**。**结果** 平均保留 1.08 和 0.78，及时报警为 4/5 和 5/6。 **分析** 分歧可以检测部分风险，在该阈值下触发过早。
- **物理残差门控**。**结果** 平均保留 1.75 和 0.25，及时报警为 4/5 和 6/6。 **分析** 残差判据在这批形态上同样以很短的保留时长换取较高检出率。
- **累计残差门控**。**结果** 平均保留 3.71 和 2.62，及时报警为 2/5 和 4/6。 **分析** 跨帧累积让门控比瞬时物理检查保留更久，同时漏掉部分违规。
- **逐帧组合门控**。**结果** 平均保留 6.45 和 5.31，及时报警为 2/5 和 3/6。 **分析** 多信号组合保留较长前缀，仍无法覆盖所有违规。
- **固定策略组合门控**。**结果** 平均保留 3.35 和 2.57，及时报警为 4/5 和 5/6。 **分析** 相对逐帧组合提高检出，缩短可用时间。
- **自适应组合门控**。**结果** 平均保留 3.82 和 2.51，及时报警为 4/5 和 5/6。 **分析** 这一自适应策略与固定组合的检出相同，两个种子的保留时长变化方向不同。
- **累计残差与自适应组合**。**结果** 平均保留 1.38 和 1.60，及时报警为 5/5 和 4/6。 **分析** 继续加入累计项使两种子的保留时间都缩短，检出收益并不一致。
- **真值可知的安全前缀对照**。**结果** 平均保留 11.35 和 9.07。 **分析** 借助实际轨迹计算可保留的安全区间，给可部署的报警器提供对照。
- **报警后的局部重试**。**结果** 分别在 7、8 个报警中改善 1 个，均未回到容差内。 **分析** 局部修补在该批报警状态上的恢复能力有限。
- **报警后的数值回退**。**结果** 所选组合策略两个种子各触发 7/8 次。数值接管后终点 17.59%→2.31%、18.25%→0.00172%，触发病例平均数值时间约 4.25 和 4.15 秒。 **分析** 改善来自混合系统在触发后重新使用数值推进，计算成本应与纯模型分开报告。

## T=100 滚动架构与修补结构

终点指标使用自由滚动。来源为 `c4cf2f9` 的 `results/supervised/rollout_t100`，包括 `seed2` 与 `refinement.json`。 128 初形对照见 `de6137e:results/supervised/runs/expanded_128`。

- **共享滚动主干的直接查询**。**结果** 两个种子的直接终点为 32.78% 和 34.24%。 **分析** 作为同一主干的控制，直接查询在这组实验中好于强行反复反馈。
- **专门训练的 T=100 CurveFNO**。**结果** 4,000 步的终点为 31.32%，自交 6/8。 **分析** 时间条件直接模型仍有长时轮廓偏差。它的结构和训练口径与共享滚动主干的直接查询各自独立。
- **直接模型反复反馈**。**结果** 两种子终点为 46.02% 和 45.58%，均有 8/8 个自交案例。 **分析** 直接模型训练输入始终是初形，重复反馈使输入偏离训练分布。
- **任意时间对更新**。**结果** 两种子终点为 32.63% 和 33.76%。 **分析** 显式学习从当前时刻到下一查询时刻的映射改善了反馈，长时偏差仍较大。
- **联合预测四帧**。**结果** 两种子终点为 32.41% 和 33.99%。 **分析** 减少反馈次数的收益与时间对更新接近，分叉稳定性仍取决于每个块的形变质量。
- **四帧加入初形锚定**。**结果** 两种子终点为 34.48% 和 31.46%，变化方向相反。 **分析** 初形锚点提供全局上下文，单独加入时收益依赖种子。
- **初形锚定加入近期法向运动**。**结果** 两种子自由终点为 28.12% 和 30.32%。每次给真值历史时为 6.00% 和 6.67%。 **分析** 法向运动历史改善局部更新。真值与自由反馈之间的差距说明模型产生的历史会持续放大误差。
- **历史输入分频带**。**结果** 单种子终点 28.05%，接近未分频的 28.12%。 **分析** 当前频带参数化带来的差异很小。
- **四帧同块修补**。**结果** 单种子自由终点为 28.56%。 **分析** 同块内再修正仍弱于该轮 Self Forcing 的 27.05%。
- **四帧流式细化**。**结果** 四次迭代终点为 30.88%，同权重只做一次时为 29.41%。 **分析** 增加细化次数在这组测试中放大了终点偏差，两种推理设置均弱于该轮 Self Forcing。
- **逐帧 Fourier 加几何分支**。**结果** 128 初形、同预算下，几何模型的 $T=100$ 终点为 21.77%，分叉 15/58，自交 5/8。直接与四帧对照分别为 26.36% 和 24.34%。 **分析** 多尺度曲率、尖端凸度、法向历史和近邻给更新提供局部结构。这组对照同时改变了反馈方式。几何模型的终点偏差最低，事件与自交表现弱于四帧。
- **原始数据的四帧保留版**。**结果** 6,000 步，粗网格终点 24.44%，原生网格 22.80%，两者自交均为 3/8。 **分析** 原生网格使四帧模型的终点更好。来源为 `152234e:results/supervised/models/nn_block/metrics.json`。
- **原始数据的逐帧几何保留版**。**结果** 6,000 步，粗网格终点 20.48%，原生网格 21.11%，两者自交均为 2/8。 **分析** 几何模型对网格变化的方向与四帧模型相反。来源为 `152234e:results/supervised/models/nn_geometry/metrics.json`。
- **128 初形的直接模型 T=100**。**结果** 6,000 步预算，终点 26.36%，事件 20/58，自交 3/8。 **分析** 该模型的分叉匹配数高于同预算几何模型，终点轮廓误差也更大。
- **128 初形的四帧模型 T=100**。**结果** 6,000 步预算，终点 24.34%，事件 19/58，自交 2/8。 **分析** 相对直接模型的终点较好，三种核心模型中该轮自交最少。
- **128 初形的直接模型 T=1000**。**结果** 终点 42.44%，事件 13/94，自交 8/8。 **分析** 延长时域后直接查询的终点偏差和自交均明显。

## T=100 滚动训练、时域安排与反馈策略

来源为 `c4cf2f9` 的 `results/supervised/rollout_t100`、`summary.json` 和 `seed2/summary.json`。只列单个值的条目为单种子。

- **真值历史微调**。**结果** 两种子自由终点为 28.74% 和 32.23%，自交均为 5/8。 **分析** 真值历史训练提供了单步对照，模型在部署时仍会接收自己产生的历史。
- **混合真值与生成历史**。**结果** 第一种子终点 29.73%，自交降至 3/8。 **分析** 混合暴露改善了部分几何有效性，终点误差未随之降低。
- **截断梯度推前**。**结果** 两种子终点为 28.03% 和 31.77%。 **分析** 用模型先行烧入后的状态训练有小幅收益，弱于同预算的三块 Self Forcing。
- **三块 Self Forcing**。**结果** 相对真值历史，终点从 28.74% 降到 27.05%、从 32.23% 降到 28.84%，自交均从 5/8 降至 4/8。 **分析** 训练时接触自身预测误差，闭环预测因此更接近部署输入。分叉偏差仍明显。
- **随时间变化的扰动噪声**。**结果** 终点为 28.93%。 **分析** 按时间设计的噪声仍与真实反馈误差有差异。
- **尖端事件加权**。**结果** 终点为 28.21%。 **分析** 增加局部径向形变监督略改善全局误差，收益低于三块 Self Forcing。
- **直达与滚动路径一致性**。**结果** 终点为 29.26%。 **分析** 预测路径之间的一致性可以约束分歧，仍需要轨迹标签校正两条路径共同偏离的部分。
- **六块从初形连续滚动**。**结果** 终点为 27.16%。 **分析** 增加展开块数接近三块 Self Forcing 的结果，继续增加长度在该预算下收益有限。
- **早段目标重采样**。**结果** 终点为 28.19%。 **分析** 调整目标帧分布能增加早期曝光，后续更新仍会积累误差。

## 数据、课程和局部纠偏训练

来源为 `b9d2d63` 的 `results/supervised/runs` 下 `dense_t100`、`geometry_equal_exposure`、`geometry_long_rollout`、`geometry_initial_starts`、`tip_density` 和 `tip_correction`。标签验算见正式数据摘要。

- **64、96、128 初形与对称增强**。**结果** 正式库覆盖 8 个主导模态族，128 初形划分为 112/8/8，$T=100$ 与 $T=1000$ 各有 177、265 帧。在线对整条轨迹同步旋转、反射和重编号。 **分析** 增强覆盖更多方向，同一轨迹的增强视图仍属于同一独立初形。分辨率差、通量和自交检验用于标签验收。
- **离线搜索挑选初形**。**结果** 8 个搜索候选对 8 个随机候选，模型分歧胜出 8/8，物理终点差异胜出 5/8，预测终点难度胜出 4/8。 **分析** 模型分歧可以筛出不同候选，目前只有选样先导，尚无重训泛化收益。
- **64→96 初形并加密早期标签**。**结果** 同一原网格下，直接 31.30%→27.29%、四帧 23.55%→20.84%、几何 22.13%→22.06%。在较密网格上，四帧 23.93%→22.86%、几何 21.37%→22.16%。 **分析** 这一步同时改了初形数和标签间距。各模型对评估网格的敏感度不同。
- **96→128 的等曝光训练**。**结果** 每个初形约 600 次抽样，几何模型两个种子的终点为 22.16%→21.80%、23.05%→21.76%。128 组从 $T=5/10/20$ 真值起步的下一帧比保持不动低 23%–56% MSE。 **分析** 独立初形覆盖改善了局部推进。自由滚动、自交和分叉匹配的收益随种子变化。
- **同一 128 初形增加优化步数**。**结果** 同种子 6,000→8,400 步后，终点为 21.77%→21.80%。 **分析** 这一预算区间内，重复抽样未带来可测的终点收益。
- **16 帧滚动加中途监督**。**结果** 两种子 $T=40$ 误差 24.78%→21.87%，分叉 36→41/116，$T=100$ 终点 21.78%→22.19%。 **分析** 更长的训练闭环帮助中段，终点没有同步改善。
- **一半片段固定从初形起步的 CPU 先导**。**结果** 3,000 步终点 24.44%→26.48%。 **分析** 提高初形起步比例会改变局部状态的训练覆盖，低预算试验出现退步。

## 诊断、推理时距和数值重锚

早期来源为 `c4cf2f9` 的 `results/supervised/rollout_t100` 下 `anchors.json`、`numerical_cost.json`、`sensitivity.json`。后段诊断见 `b9d2d63` 的 `results/supervised/runs/geometry_equal_exposure`、`geometry_initial_starts` 和 `drift_diagnostic`。

- **T=40 与 T=80 两次真值重锚**。**结果** 终点与只在 $T=80$ 重锚相同，时间平均误差为 11.23% 和 11.24%，低于只重锚一次的 18.79% 和 18.31%。 **分析** 较早的锚点改善中段，最后一次真值替换主导终点。
- **自适应真值重锚**。**结果** 终点仍同 $T=80$ 重锚，时间平均误差为 5.76% 和 5.90%。 **分析** 额外数值锚点降低轨迹误差，收益依赖混合推理的计算与真值访问。

- **长时分歧门控**。**结果** 两个种子都在 8/8 个案例及时报警，平均保留时间只有 0.229 和 0.057，未门控为 61.37 和 74.38。 **分析** 过早拒绝会缩短可用预测。数值接续的前缀成本也需要计入。

- **T=5、10、20 真值界面重启**。**结果** 128 初形组的一步误差低于保持形状的对照。从 $T=20$ 起步的半步误差约 0.4%，到 $T=40$ 仍达 8.5%–10.6%。 **分析** 即使消除早期偏差，后续局部误差仍会累积。
- **分叉出生窗口与保持不变对照**。**结果** CUDA 16 帧课程的局部 MSE 胜出数在增加初形起步后由 41/42 降至 37/38，CPU 先导为 44→45。训练事件按 $T<20$、20–50、50 以后统计为 357、226、193。 **分析** 自由滚动收益与局部保持形状对照的排序可以不同，事件按时间分段的覆盖也不均匀。
- **同状态自由滚动与真值逐步替换**。**结果** 8 个新初形中选得来自 6 个形态的 16 条配对路径。走偏起步后 +4，逐步给同状态数值界面为 0.176%，自由滚动为 1.261%，物理轨迹相对原轨迹自身为 1.015%→1.084%。 **分析** 从相同界面出发可以把物理敏感性与网络反馈误差分开。
- **有符号法向误差一致性**。**结果** 跨步一致性约为 0.996–0.999。 **分析** 误差长期指向相近方向时更易累积。法向对齐和弧长点序跟踪限制了解释范围。
- **标量运动幅值校准**。**结果** 用 42 个训练窗口得到增益 0.57669、0.58029。独立走偏半步的全局误差为 0.1703%→0.1677%、0.1782%→0.1699%，扇区分别为 0.1023%→0.1142%、0.1161%→0.1150%。 **分析** 单个比例可以改善部分整体幅值，尖端扇区未稳定受益。
- **后段推理步长降至 0.5**。**结果** 两个种子的独立终点分别为 24.46%→23.81% 和 21.78%→21.89%，分叉 28→27 和 20→20。 **分析** 仅提高反馈频率未稳定改善终点和分叉。

## 物理标签、输入和融合结构

历史指标见 `b9d2d63` 的 `results/supervised/runs/normal_velocity_labels`、`drift_diagnostic`、`physics_inputs` 与 `physics_fusion`。除非单独说明，速度 RMSE 与轮廓偏差采用各自原报告的尺度。

- **高分辨率瞬时法向速度标签**。**结果** 1024/1536 点检验短轨迹，速度验算最高到 3072 点，共 252 个训练状态和 48 个评估状态。 **分析** 短时位置差与瞬时速度在走偏状态下有可测差异，标签可提供符号方向。
- **短时位移差与瞬时速度审计**。**结果** 0.05/0.5 两个时距相对瞬时速度的 RMSE 在干净状态为 0.00040/0.00255，在走偏状态为 0.03342/0.04147。 **分析** 走偏状态上，位移差和瞬时速度的差异更大，二者应各用匹配的监督口径。
- **同状态位置与回放控制**。**结果** 热启动与位置加回放控制的速度 RMSE 为 0.12533 和 0.12706，$T=100$ 终点为 23.12% 和 22.54%，原生分叉为 48 和 41/122。 **分析** 热启动后的坐标训练能改善整体轮廓，分叉事件并未随之增加。
- **瞬时法向速度加到坐标监督**。**结果** 速度 RMSE 0.12706→0.12029，走偏后 4 单位误差 1.241%→1.167%，终点 22.54%→22.44%，走偏分叉 14→15/37。 **分析** 瞬时速度对局部运动更直接，长时收益较小。
- **法向速度残差头**。**结果** 800 步两种子下，同状态 +4 自由误差从 1.21365% 变为 1.21429%、从 1.18721% 变为 1.18807%。残差头的半步贡献约为 0.0010%–0.0017%R。 **分析** 残差头的实际输出幅度很小，主要演化路径变化有限。
- **等容量几何控制头**。**结果** 速度 RMSE 0.12029→0.11998，终点 22.44%→22.40%。 **分析** 只增容量也有同量级变化，因此物理输入应与等容量控制比较。
- **三处空间近邻输入**。**结果** 相对等容量控制，速度 RMSE 0.11998→0.11988，走偏分叉 15→16/37。 **分析** 对侧法向和邻域方向提供少量局部信息。
- **双尺度精确历史通道**。**结果** 速度 RMSE 0.11998→0.11985，终点 22.40%→22.41%。 **分析** 新增历史侧路参与预测的程度有限。
- **邻域与历史联合输入**。**结果** 速度 RMSE 0.11998→0.11974，走偏后 4 单位误差 1.1645%→1.1614%，整轨近乎持平。 **分析** 遮挡后输出变化较小，两个附加通道在这版融合结构中作用较弱。
- **直接替换原历史尺度**。**结果** 速度 RMSE 升到 0.12590，终点 23.33%，自交 3→5。 **分析** 改写尺度改变了暖启动主干原有的输入分布。
- **多近邻融合进 Fourier 主干**。**结果** 扇区 RMSE 0.11971，走偏后 4 单位误差 1.166%，终点 22.425%。配对基线依次为 0.11989、1.167%、22.442%。 **分析** 全局主干融合带来的变化很小，长时收益随种子变化。
- **多近邻融合进几何分支**。**结果** 扇区 RMSE 0.11962，走偏后误差 1.164%，终点 22.442%。 **分析** 物理通道直接参与法向位移，局部误差略降，终点持平。
- **主干与几何分支同时融合**。**结果** 扇区 RMSE 0.11948，走偏后误差 1.163%，终点 22.436%，自交 3→4/16。遮挡改变约 3.4%–3.8% 的半步位移。 **分析** 双路融合增强了模型对输入的依赖，新增信息对整轨精度的贡献仍小。

- **直接模型加指尖与凹槽项**。**结果** 终点 28.76%，两种子均下降，事件合计为 14/122，变化方向相反。 **分析** 指尖空间监督改善了终点轮廓，对事件的收益随种子变化。整段仍有 16/16 条轨迹曾自交。
- **坐标模型加指尖与凹槽项**。**结果** 终点 22.48%，事件 51/122，扇区 0.557%，自交 3/16。 **分析** 局部形态和分叉事件受益，终点最大偏差增加。
- **直接模型加自交惩罚**。**结果** 终点 30.44%，事件 9/122，仍有 16/16 条曾自交。 **分析** 能惩罚已发生的交叉，对独立初形上的自交计数没有稳定收益。
- **坐标模型加自交惩罚**。**结果** 终点 21.89%，事件 44/122，扇区 0.736%，自交 6/16。 **分析** 交叉项对这轮滚动预测的影响近乎为零。
- **直接模型低权重组合**。**结果** 终点 28.98%，占据 IoU 为 67.61%，事件 8/122。 **分析** 多个形状目标可以提升区域重叠，事件匹配依然下降。
- **坐标模型低权重组合**。**结果** 终点 21.93%，事件 50/122，扇区 0.600%，自交 4/16。 **分析** 局部和事件有收益，平均最大终点偏差没有下降。
- **走偏后的多步数值标签**。**结果** 坐标模型自由更新四次，只在已有数值端点监督。标签跨度 0.055–0.5，终点 21.77%，事件 48/122，扇区 0.713%，自交 5/16。 **分析** 短窗标签只带来小幅收益。所有坐标组在 32 条路径上相对原轨迹均无误差收缩。

## 同一走偏起点的短窗与长窗监督

三组均保留指尖损失。短窗和长窗共用 32 个训练初形的走偏起点，每 0.5 查询一次，两种子各训练 1,200 步。短窗与长窗的辅助权重 8.95986 和 0.378833，使热启动参数梯度范数约为局部目标的 0.75 倍。

- **共享长窗数值标签**。**结果** 32 个独立训练初形覆盖 7 个主导模态，初始偏差约 0.345%–1.984%，1024/1536 节点的最大差约 0.0116%。 **分析** 短窗和长窗可以从逐位相同的起始界面比较，双分辨率检查限制了标签不确定性。
- **仅指尖监督的配对对照**。**结果** 同状态 +4 扇区误差为 0.5458%，相对原轨迹为 1.1895%，终点 21.84%，分叉 45/122，自交 2/16。 **分析** 这是两种额外续算监督的共享基线。
- **短窗 +0.5 监督**。**结果** 同状态 +4 扇区 0.5430%，相对原轨迹 1.1853%，终点 21.89%，分叉 47/122，自交 2/16。 **分析** 增加同状态局部标签只有很小的推进收益，原轨迹误差没有收缩。
- **长窗 +4 多步监督**。**结果** 同状态 +4 扇区 0.5433%，相对原轨迹 1.1860%，终点 21.84%，分叉 46/122，自交 2/16。 **分析** 相对短窗的局部收益方向在两种子间相反，局部事件均为 16/30。
- **按物理自然收缩分层**。**结果** 数值续算在 10/32 条路径的分叉扇区自然收缩，集中在 2 个初形，另有 19 条继续分离、3 条小于分辨率差异。在自然收缩组，数值从 0.753% 降到 0.714%，长窗模型升到 1.167%。三组模型总体均为 0/32。 **分析** 区分真实扰动的演化与模型额外累积的误差。自然收缩组的独立形态覆盖较小。

## 有设计或入口、缺少独立结果的方向

这些条目用于区分已测实验与仅实现、讨论过的方向。

- **仅训到 T=5、10、20 后预测 T=100**。**结果** 现有归档没有找到该独立外推对照。已有三档直接与短窗对照是在各自训练时域内测试，另有 T=5、10、20 的真值重启诊断。 **分析** 域内预测、重启和时域外推是不同设定，现有数字不能用于评估外推能力。
- **早期逐帧纯 Fourier 消融**。**结果** 历史代码包含关闭几何分支的入口，早期归档缺少匹配的独立测量。本轮补测见后面的逐帧几何分支对照。 **分析** 早期核心架构对照同时改变了反馈方式和几何特征。
- **AlphaZero 式在线搜索与端到端分叉校正**。**结果** 现有记录里没有找到在线搜索或独立端到端分叉校正器的配对结果。已完成的是离线初形选样、同帧修补和走偏监督。 **分析** 这些已完成试验可以分别说明选样、局部修补和推进精度，在线搜索及独立校正策略仍需自己的对照。

## 八帧反传、扰动响应与旋转对称性

沿用 112 个训练初形和 8 个验证初形。诊断集是此前反复评估的 128–135 号初形，封存集是新增的 136–143 号初形，每个主导模态一个。后者的 177 帧通过双分辨率检验，最大轮廓差为 0.050%R。下文的终点误差均为逐初形的双向最大轮廓距离取平均；分叉是按时刻和方位匹配的持续径向峰值。两个训练种子复用同一批测试形态。

- **连续八帧反传**。**结果** 从同一几何检查点微调 240 步，截断组与完整组使用相同的八次前向更新、抽样、增强和监督位置。固定末步，封存集终点由 21.42% 降至 20.57%，诊断集由 23.03% 升至 23.41%。**分析** 保留跨帧梯度改变了更新方向；对终点的收益随形态集合改变。原权重在封存集为 20.32%。
- **按原生时间网格的终点轮廓选权重**。**结果** 候选为第 0、80、160、240 步。以稀疏网格坐标 MSE 选择时，封存集的截断、完整反传分别为 20.32%、20.10%；改用验证集原生网格终点轮廓，两组分别为 20.62%、20.96%。完整反传的两种子验证轮廓均降到约 21.35%，原权重为 22.99%。**分析** 8 个验证初形的轮廓改善未稳定传到新形态。允许选第 0 步能揭示微调是否优于已有权重。
- **分叉前的成对扰动盲测**。**结果** 在未来分叉附近沿法向对同一界面施加正、负 0.8%R 的局部凸起，各自恢复到目标面积，离线用 768、1024 点续算。以两帧数值输入提供初始历史，随后自由推进八次、共 4 个时间单位。冻结模型在诊断集判对 17/38 个局部径向响应方向，封存集为 20/31。封存集的变化量 MAE 为 0.1220%R，假设两条界面的差值保持不动为 0.0620%R。**分析** 五个方位测的是局部径向包络对扰动的响应。判符号时排除低于双分辨率差异两倍或 0.01%R 的变化。封存集有 7 个合格母形态，139 号的分叉均早于预设时段。相邻测点相关，统计单位仍是初形。
- **普通分叉窗口补标**。**结果** 46 个训练母形态各补一条未扰动的细时间窗。与下两组固定主回放、优化步数、辅助样本数和学习率。按验证轮廓选择后，封存集终点为 21.34%，两种子分叉均为 17/54。**分析** 普通精细续算提供了相近的标注预算对照。该组复用原训练库的母形态，可检验新增局部窗口的价值。
- **成对窗口只监督坐标**。**结果** 24 个训练母形态各生成正负两个窗口，覆盖八个主导模态。封存集终点为 21.52%，两个种子均匹配 18/54 个分叉，局部响应 MAE 均约 0.1200%R。**分析** 把轻微扰动加入训练分布，只有小幅局部收益。两条近邻轨迹间的差异在普通坐标损失中权重较小。
- **显式监督正负扰动之间的差值**。**结果** 在相同 48 条续算上匹配五个方位的包络差，按训练样本梯度校准权重为 37.22。封存集响应 MAE 为 0.1036%、0.1063%R，诊断集为 0.1050%、0.1059%R。封存集两种子的方向均为 21/31，终点分别为 22.22%、22.05%，分叉匹配 18/54、15/54。**分析** 差值监督在两套数据上都改善了响应幅度，但该局部任务尚未改善完整轨迹。当前证据支持保留响应评测，暂缓扩大同类标签。
- **单独改变输入朝向**。**结果** 在原诊断集，对相同初形旋转 0.73 弧度或作镜像，将两份预测放回同一坐标系，终点轮廓分别相差 19.28%R、23.62%R。**分析** 训练时的旋转反射增强仍允许长时轨迹依赖坐标系。这项测量比较两次网络预测，和对数值真值的偏差分别计算。
- **冻结权重，以最长初始半径固定坐标系**。**结果** 封存集终点 20.32%→19.69%，诊断集 23.14%→21.92%，两组均有 6/8 个初形改善。封存集分叉仍为 19/54、自交仍为 2/8，首次错报或漏报分叉的中位时刻为 8.75→9.63。**分析** 无需新增标签，每步一次网络调用即可获得小幅轮廓收益。近等长指尖的选轴可能切换，尚未验证这类初形上的稳定性。
- **在初形坐标系内继续微调**。**结果** 按验证轮廓选权重，封存集两个种子的终点分别为 20.32%、20.21%，首次错误分叉的中位时刻为 11.38、12.38，自交均为 1/8，分叉匹配为 17/54、16/54。**分析** 微调延后了首次错误，但冻结权重固定朝向的整体轮廓更准；首次错误时间与整个时域召回的排序不同。
- **冻结权重，逐步平均八个对称视角**。**结果** 每步对四个旋转及其镜像预测后逆变换、取均值并恢复面积。验证集终点 22.99%→18.91%，诊断集 23.14%→19.45%，封存集 20.32%→18.49%。封存集分叉 19/54→18/54，曾自交的初形 2/8→4/8，首次错误分叉的中位时刻 8.75→11.88。**分析** 消除一部分朝向依赖带来本轮最大的轮廓收益。平均后的更新仍能生成相交曲线，而且每步处理八个网络视角。

- **相同逐帧反馈下开关几何分支**。**结果** 两组从同一 Fourier 热启动出发；新增分支的输出层置零，两种子第 0 步的验证轮廓误差相同。适配 480 步，按验证终点轮廓选权重，封存集两个种子分别为 33.64%→33.32%、33.76%→33.52%；诊断集为 34.42%→34.46%、31.87%→32.03%。封存集分叉由每种子 10/54 变为 9/54、8/54。**分析** 反馈频率固定后，短预算下单独加分支的收益较小，且随测试集改变。这一对照从较早的共享权重起步，不能据此推算充分训练后的分支贡献。

封存集的原模型、固定朝向、八视角三组分别累计有 46、78、44 个自交帧，恰在 $T=100$ 自交的初形分别为 2、0、0 个。每组共 8×177 帧。“曾自交初形数”衡量影响范围，“自交帧数”也受单次持续时间影响。


## 等变边界算子与全边界积分

四组逐帧模型各用种子 541、542 从头训练 2400 步，batch 为 8，共用 112 个训练初形、坐标损失、时间安排和旋转反射增强。同种子各组使用相同的训练批次。每 400 步在 8 个验证初形上按 177 帧自由滚动的终点轮廓挑选权重。Fourier 对照使用现有滚动主干。等变组把绝对坐标换成几何标量，沿弧长使用实偶 Fourier 核，再用外法向、径向和带符号的切向组合更新坐标。等变组宽度由 40 调为 56，四组参数量为 84.63–85.58 万。

积分分支以局部弧长加权，汇总整条界面的半径、弯曲、法向朝向与运动特征；由两点相对方位角的九个余弦模态调节源点对接收点的贡献。一次网络前向完成一个时间步。主要盲测使用新增的 144–151 号初形，八个主导模态各一个，双分辨率核验的最大轮廓差为 0.049%R。128–143 号只作复核。成熟几何模型使用既有权重，用于衡量更换模型的实际价值。

- **共享 Fourier 主干从头训练**。**结果** 新盲测的两个种子终点误差为 32.40%、32.61%，分别匹配 4/57、8/57 个分叉，两组均有 8/8 条轨迹曾自交。**分析** 该预算下，普通坐标回归对长时分叉和细部几何的约束很弱。
- **只加全边界积分**。**结果** 新盲测终点为 27.84%、32.43%，分叉匹配 1/57、0/57，两组均有 8/8 条轨迹曾自交。**分析** 积分能在远隔弧段间传播梯度，单独加入这一组方位角模态主要改变轮廓偏差，分叉命中率下降。
- **严格等变的标量编码与向量更新**。**结果** 两个种子终点 21.17%、22.35%，分叉匹配 15/57、14/57，曾自交 6/8、4/8。先在每个初形上平均两种子，三个测试集的 24 个独立初形中有 23 个终点优于 Fourier 对照。新盲测改善 10.74 个百分点，对八个母形态做配对自助重采样得到的 95% 区间为 8.06–13.81 个百分点。**分析** 这是不变量输入、实偶谱核与向量解码这一整套结构的收益。两个种子的结果重复使用同一批初形，区间只描述形态抽样的不确定性。
- **同时使用等变更新与全边界积分**。**结果** 终点 27.94%、24.44%，匹配 6/57、10/57，曾自交 7/8、6/8。**分析** 两个种子的轮廓和分叉都弱于单独等变。当前低阶、可分离的积分核尚未把远端信息稳定转化为更准确的指尖竞争。
- **分叉前的成对扰动响应**。**结果** 在 7 个母形态、31 个可辨方向上，Fourier 两种子判对 20、18 个，单独等变判对 20、16 个。两组响应幅度 MAE 平均为 0.0883%R、0.0771%R，保持原差值为 0.0620%R。**分析** 整体轮廓改善传递到了部分幅度指标，判定微扰放大方向的能力仍有限。
- **固定末步权重的稳定性复跑**。**结果** 单独等变的种子 541 完整重训后，六次验证数值均复现。第 1600 步的平均终点误差为 23.70%R；第 2400 步的验证初形 46 从 $T=19$ 开始有坐标超出 $3R$，终点偏差达 $6.24\times10^6R$。逐帧施加指数谱滤波（波数 256 衰减至 $1/e$）后，该末步权重在此例的终点偏差为 48.18%R；滤波对验证标签的单次最大点位改变量为 0.0096%R。**分析** 最短波长的扰动参与了这次失稳。抑制它们可以阻止这条轨迹跑飞，低频形状误差仍然存在。
- **现有几何架构等预算重训**。**结果** 同样从头训练 2400 步，新盲测为 24.64%、24.27%，匹配 5/57、6/57，曾自交均为 7/8。单独等变平均改善 2.69 个百分点，两个种子平均后有 6/8 个初形改善。此前充分训练的几何权重则为 19.97%、23/57、自交 1/8；固定初形朝向为 20.77%、16/57、自交 2/8。**分析** 单独等变在这档预算内优于现有架构，尚未达到现有生产权重的精度。此前固定朝向的收益在新增初形上也出现反转。
- **遮蔽全边界积分场**。**结果** 保留接收点的局部特征，仅将积分场置零。只加积分的两个种子在同一干净短步的位移分别改变 10.85%、15.36%，盲测终点由 27.84%→30.88%、32.43%→31.30%；同时等变与积分的两组位移改变 5.03%、7.85%，终点由 27.94%→27.35%、24.44%→26.81%。**分析** 网络使用了远端信息，其效果随权重和形态变化，遮蔽实验只能衡量已训练权重的依赖程度。
- **变换一致性与计算精度**。**结果** 训练后对非零时间步验证任意角度样例、镜像、循环重编号及其组合，等变组的 FP64 单步点位差在 $10^{-14}R$ 内。对新盲测连续推进 177 帧，组合变换前后的终点轮廓差在默认精度下，单独等变为 0.467%、0.007%R，双模块为 11.393%、0.418%R。将同一权重和输入升至 FP64 后，前两项小于 $10^{-8}$%R，双模块种子 541 仍有 0.013%R。**分析** 单步代数对称性成立；多步反馈能放大浮点误差，尤其是积分与等变叠加的个别权重。
- **最佳验证权重上的高频衰减**。**结果** 给单独等变的两个种子添加同一滤波后，新盲测终点由 21.17%→21.72%、22.35%→22.35%；双模块为 27.94%→28.59%、24.44%→24.44%。**分析** 对灾难性失稳的抑制没有转化为最佳权重的平均精度提升。
- **八视角平均在第三组独立初形上的复核**。**结果** 在 144–151 号上，成熟几何模型的终点误差由 19.97% 降到 16.16%，分叉匹配由 23/57 增至 26/57，曾自交的初形由 1/8 增至 5/8。**分析** 八次前向平均改善轮廓距离，也扩大了出现折叠的范围。

后续保留每步一次前向的严格等变 `nn_boundary`，选用预先指定的第一种子 541 在验证集最优的第 1600 步权重，验证终点为 23.70%R。成熟几何模型继续作为整轨精度基准。

## 六种初形的终点界面对比

- **三种模型在全部独立初形上的终点误差**。**结果** 对 128–151 号共 24 个初形计算 $T=100$ 的双向最大轮廓距离，`nn_direct/model.pt`、`nn_geometry/finetuned.pt`、`nn_boundary/model.pt` 的逐例平均分别为 **27.26%、20.36%、24.80%R**。滚动模型均从初形出发，使用完整的 177 帧时间网格。**分析** 这三个实际权重中，微调几何模型的平均误差最低。上节的 19.97% 来自另一份成熟几何权重和 8 个初形，两处的对照条件不同。
